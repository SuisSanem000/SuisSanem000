# Eye Server

Server component for the News Feed App, responsible for news aggregation, data processing, and API endpoints.

## Tech Stack

- **Node.js** - Server runtime
- **RESTful API** - Backend architecture

## Purpose

This server handles news aggregation from multiple sources, data processing, and provides API endpoints for the news feed client application.
