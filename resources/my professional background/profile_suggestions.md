# Suggestions to Improve GitHub and LinkedIn for Job Hunting

Here is a list of actionable suggestions to maximize your chances of landing a top Full-Stack Web Developer role based on your current profile state:

## 🐙 GitHub Profile Improvements
1. **Pin Your Best Repositories:** Ensure that the repositories for the JSON Generator (VS Code Extension), JSON Generator (npm package), and the High-Performance React Grid are explicitly pinned to the top of your GitHub profile page so recruiters don't have to hunt for them.
2. **Add Live Demos:** For any frontend projects (like the React Grid Component or UI clones), ensure there is a live Vercel/Netlify link at the top of the repository's "About" section. Recruiters love clicking links that instantly work.
3. **Keep the Contribution Graph Active:** Try to maintain a green contribution graph. If your recent work at TreeScribe is private, ensure your GitHub settings are configured to show private contributions on your profile so recruiters can see you code every day.
4. **Add Badges to Repositories:** Add an NPM download badge or a VS Code Marketplace install badge directly into the README files of those specific repositories to instantly prove the "630K+ installs" metric.

## 💼 LinkedIn Profile Improvements
1. **Utilize the "Featured" Section:** LinkedIn has a specific "Featured" section right below your summary. Add direct links here to:
   - Your VS Code Extension on the marketplace.
   - Your NPM package.
   - Your most successful technical article on Dadroit.com.
2. **Gather Recommendations:** Since you drove a 540% increase in organic growth via SEO and technical writing, ask your former CTO or team members at Parsaiane to write a LinkedIn recommendation explicitly validating those numbers. External validation is incredibly powerful for metrics like these.
3. **Clarify the Parsaiane vs. Dadroit Confusion:** Currently, your Technical Writer role is listed under "Dadroit" while your other roles are under "Parsaiane". This can confuse recruiters into thinking you were job-hopping or working multiple full-time jobs at competing companies. List "Parsaiane" as the sole company, and list Dadroit as a product *underneath* it, or explicitly state "Dadroit (A product of Parsaiane)" to show career stability.
4. **State Your Availability Clearly:** At the very end of your LinkedIn "About" summary, add a bold line stating exactly what you are looking for. Example: **"Currently seeking Senior/Lead Full-Stack Web Developer roles (Remote/Europe)."** This saves recruiters time and tells them you are actively open to offers.
5. **Add Open-Source / Projects:** Make sure the JSON Generator is explicitly added to the "Projects" section of your LinkedIn profile and tag your specific co-creators or technologies used.
